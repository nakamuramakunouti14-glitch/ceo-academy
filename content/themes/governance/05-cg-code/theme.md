## 要点

- **コーポレートガバナンス・コード**（CG コード）は、東京証券取引所（東証）が示す、上場会社向けの原則集です。いまの版は、2026年7月21日に確定・公表された改訂版です
- コードの各原則には、**法的な拘束力はありません**。原則を守るか、守らない理由を十分に説明するかを選びます。これを「コンプライ・オア・エクスプレイン」と呼びます
- 細かいルールを決める形ではなく、大きな原則を示す形（プリンシプルベース）です。言葉の形にとらわれず、原則の趣旨に合っているかで考えます

## 4つの基本原則

2026年の改訂で、基本原則は次の4つに整理されました。

| 基本原則 | 中身 |
|---|---|
| 株主の権利・平等性の確保、株主との対話 | 株主が権利を使える環境を整え、平等に扱う。株主総会の場以外でも、株主と建設的に対話する |
| 株主以外のステークホルダーとの適切な協働 | 従業員・お客様・取引先・債権者・地域社会と、適切に協力する |
| 適切な情報開示と透明性の確保 | お金の情報と、戦略・リスク・ガバナンスなどお金以外の情報を、正確でわかりやすく出す |
| 取締役会等の責務 | 取締役会が、会社の大きな方向を示し、経営陣がリスクをとれる環境を整え、独立した立場で監督する |

## 独立社外取締役

コードは、会社から独立した立場の社外取締役（独立社外取締役）に、次の役割を期待しています。

- 経営陣幹部の選任・解任などを通じて、経営を監督する
- 会社と、経営陣や支配株主との利益のぶつかり（利益相反）を監督する
- 少数株主などの意見を、取締役会に反映させる
- 自分の知見から、会社の成長に向けて助言する

人数について、プライム市場の上場会社は少なくとも**3分の1以上**、そのほかの市場の上場会社は**2名以上**選ぶべきだとしています。支配株主（株の多くを持つ親会社など）がいる会社は、支配株主から独立した独立社外取締役を、プライム市場なら少なくとも過半数、ほかの市場なら3分の1以上選ぶべきだとしています。適切と考える場合は、その代わりに、独立した人たちで作る特別委員会を置き、支配株主と少数株主の利益がぶつかる大事な取引を話し合う方法も示されています。

## 上場していない会社での使い方

このコードは上場会社向けです。上場していない会社に、守る決まりはありません。それでも、取締役会の動かし方を見直す手がかりになります。

- 取締役会の資料を、会議の前に十分早く配る
- 社外の目を入れ、反対の意見も言える場にする
- 内部通報の窓口を、経営陣から独立した形で置く
- 中期経営計画が届かなかったときは、原因を分析して次の計画に生かす

## 経営者が見るところ

- **取締役会の役割**：方向を示す、リスクをとる環境を整える、監督する。この3つができているか
- **社外の目**：社外取締役や顧問など、経営陣から独立した人の意見が入っているか
- **説明の中身**：決めたことの理由を、株主や銀行にわかる言葉で説明できるか
