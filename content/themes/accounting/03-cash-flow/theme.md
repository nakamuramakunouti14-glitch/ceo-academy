## 要点

- キャッシュフロー計算書（CF）は、**1年間に、現金がどこから入って、どこへ出ていったか**を表す表です
- 現金の動きを、**営業・投資・財務**の3つに分けます
- PL が黒字でも、現金が足りなくなることがあります。黒字なのに現金が尽きて、会社がつぶれることを黒字倒産（くろじとうさん）といいます。だから、利益と現金の両方を見ましょう
- 3つの表はつながっています。**PL の当期純利益 → BS の利益剰余金**、**CF の合計 → BS の現金の増減** です

## 利益と現金はずれる

利益と現金がずれるおもな理由は、3つあります。

| 理由 | 例 | 利益と現金のくらべ |
|---|---|---|
| 費用だが、現金は出ていかない | 減価償却費（建物の代金は、ふつう買った年に払い終えている） | 現金のほうが多い |
| 売上だが、まだ現金が入っていない | 旅行会社を通した予約の売掛金（あとで受け取る代金） | 現金のほうが少ない |
| 費用ではないが、現金が出ていく | 借金の返済、建物を買うお金 | 現金のほうが少ない |

## CF は3つに分ける

| 区分 | 中身 | 元気な会社のふつうの向き |
|---|---|---|
| 営業キャッシュフロー | 本業で生んだ現金 | プラス |
| 投資キャッシュフロー | 設備や会社を買う・売るお金 | マイナス（これからのための投資） |
| 財務キャッシュフロー | お金を借りる・返す、増資、配当 | 借金を返している時期はマイナス |

営業キャッシュフローと投資キャッシュフローを足したものを、**フリーキャッシュフロー**といいます。会社が自由に使える現金、という意味です。投資はふつうマイナスなので、本業で得た現金から、投資に使った現金を引いた額になります。借金の返済や配当に回せる現金の目安です。

## みなと館ホテルの CF を読む

架空の「みなと館ホテル」の1年間の CF です。単位は万円です。学びやすいように、当期純利益から始める簡単な形にしています（法人税は、その年に払い終えたとします）。

| 区分 | 項目 | 金額 |
|---|---|---|
| 営業 | 当期純利益 | 3,500 |
| 営業 | 減価償却費を足し戻す | 5,000 |
| 営業 | 古い設備を捨てたときの損を足し戻す | 500 |
| 営業 | 売掛金が増えた分を引く | −500 |
| 営業 | 買掛金（かいかけきん：まだ払っていない仕入れの代金）が増えた分を足す | 200 |
| **営業キャッシュフロー** | | **8,700** |
| 投資 | 客室の設備の入れかえ | −6,000 |
| **投資キャッシュフロー** | | **−6,000** |
| 財務 | 借入金の返済 | −4,000 |
| 財務 | 株主への配当 | −500 |
| **財務キャッシュフロー** | | **−4,500** |
| **現金の増減** | 8,700 − 6,000 − 4,500 | **−1,800** |

年のはじめの現金は 9,800 万円でした。そこから 1,800 万円減って、年の終わりは 8,000 万円です。これは BS の現金・預金 8,000 万円と同じです。

フリーキャッシュフローは、8,700 − 6,000 ＝ 2,700 万円です。借金の返済 4,000 万円には足りません。足りない分は、手元の現金を取りくずして払ったとわかります。PL が黒字でも、これが続けば現金は減り続けます。

## 3つの表のつながり

1. **PL → BS**：当期純利益 3,500 万円から配当 500 万円を引いた 3,000 万円が、BS の利益剰余金に積み上がります
2. **PL → CF**：営業キャッシュフローは当期純利益から始めて、現金が動かない費用を足し戻します
3. **CF → BS**：CF の合計（−1,800 万円）が、BS の現金が前の年から増えた・減った分と同じになります

このアプリでは、どの分野の判断も、最後はこの3つの表にどう効くかで確かめます。値上げも、採用も、DX 投資も、PL・BS・CF のどの行がどれだけ動くかで比べられます。
