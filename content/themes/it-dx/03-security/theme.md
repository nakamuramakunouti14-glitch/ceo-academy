## 要点

- 守りたいのは2つです。**止まらないこと**（予約やレジが使える）と、**漏れないこと**（お客様の情報）です
- よくある被害は3つです。にせのメールで ID やパスワードを盗まれること。**ランサムウェア**（データを使えなくして、身代金を求める攻撃）。そして、人のまちがい（送り先のまちがい、なくし物）です
- 多くは、**基本の5つ**の対策で防げます。防げなくても、被害を小さくできます

## 基本の5つ

| 対策 | 中身 |
|---|---|
| 2段階の確認 | パスワードに加えて、スマホに届くコードなどで本人を確かめる（多要素認証） |
| 更新 | パソコンやソフトの更新を、すぐに入れる |
| 見られる人をしぼる | 仕事に必要な人だけが、必要な範囲で見られるようにする |
| バックアップ | 大事なデータの写しを、ネットにつながっていない別の場所にも取っておく。元に戻せるかも試す |
| あやしいメールを開かない | 添付やリンクを開く前に確かめる。迷ったときに聞ける相手を決めておく |

## 止まったときの損を考える

みなと館ホテルの、予約と客室の管理システムが、ランサムウェアで 3 日止まったとします。

- 新しい予約を受けられない。誰がどの部屋にいるかわからない
- 紙の台帳で回すための人手と、まちがいへの対応
- お客様の情報が漏れていれば、報告と、おわびの連絡

バックアップから元に戻せれば、止まる期間を短くできます。だから、バックアップは取るだけでなく、本当に戻せるかを試しておきましょう。

## 経営者が見るところ

- **5つの対策ができているか**：特に、2段階の確認とバックアップ
- **止まったときの手順**：紙の台帳、誰に連絡するか
- **従業員が辞めるとき**：その人のアカウントを、すぐに止めているか
