# CEO アカデミー

経営者（CEO）に必要な知識を、13の分野に分けて学ぶ学習アプリ。
どの分野の判断も、最後は財務3表（損益計算書・貸借対照表・キャッシュフロー計算書）にどう効くかで確かめる。

**開く：https://nakamuramakunouti14-glitch.github.io/ceo-academy/**

ブラウザだけで動く。インストールやログインは要らない。
iPhone では Safari で開き、共有ボタンから「ホーム画面に追加」すると、アプリのように開ける。

## 中身

- 13の分野：財務、ファイナンス、M&A・投資判断、経営戦略、マーケティング、現場の運営管理、人事・組織づくり、リーダーシップ・意思決定、交渉・プレゼン、法務、税務、ガバナンス・リスク管理、IT・DX
- 80のテーマ：基礎のテーマ 41 と、有名な理論・名著のテーマ 39（ポーターの5つの力、VRIO、DCF 法、心理的安全性、コッターの変革8段階、ハーバード流交渉術、NIST CSF 2.0 など）。各テーマに、解説と確認クイズ5問がある
- 19のケーススタディ：分野ごとのケース 13 と、いくつもの分野をまたぐ横断ケース 6。横断ケースでは、1つの判断（値上げ、出店、DX 投資、金利の上昇など）を分野の順に考え、最後に財務3表の増減を確かめる
- 舞台は架空のホテル「みなと館ホテル」と架空の定食屋「うみかぜ食堂」。会社・人・数字はすべて作りもの
- 法務・税務のテーマには、出典（法令・公的機関のページ）と、いつの時点の情報かを書いている。法令や制度は変わるので、実際の判断には最新の原典と専門家の確認が要る

## 使い方

- **地図**（最初の画面）：13分野と財務3表のつながりを1枚の図で見る。今日のケースもここから始める
- **つながり**：分野を1つ選ぶと、つながる分野とその理由が出る
- **分野**：分野ごとのテーマとケースの一覧。進み具合も見られる
- **テーマ**：解説を読み、クイズ5問に答える
- **ケース**：社長の立場で案を選び、理由を考え、財務3表への効果を確かめる
- **復習**：間違えた問題を、忘れかけたころにもう一度出す。正解が続くほど、次に出るまでの日にちがあく
- **記録の書き出しと読み込み**：学習の記録は、使っている端末のブラウザの中だけに保存する（サーバーには送らない）。別の端末へ移すときは、ファイルに書き出して読み込む

## 作り

- 言語と部品：TypeScript、[Next.js](https://nextjs.org/)（画面の組み立て。静的な HTML に書き出して配信）、[React](https://react.dev/)、[Tailwind CSS](https://tailwindcss.com/)（見た目）
- 記録の保存：[Dexie](https://dexie.org/)（ブラウザの中のデータベース IndexedDB を使う部品）
- 復習の間隔：[ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs)（間隔反復のしくみ FSRS）
- 教材の形の確かめ：[zod](https://zod.dev/)、テストは [Vitest](https://vitest.dev/)
- 教材はプログラムと分けて、Markdown（解説）と YAML（クイズ・ケース）で書いている。書き方は `docs/content-format.md`、文の決まりは `docs/easy-japanese.md`

```
content/
  fields.yaml          13分野と、分野どうしのつながり
  themes/<分野>/<番号-名前>/
    theme.md           解説（つながる先のテーマ、出典と時点も書く）
    quiz.yaml          確認クイズ5問
  cases/               ケーススタディ（財務3表の増減つき）
src/
  app/                 画面（地図・つながり・分野・テーマ・ケース・復習・記録）
  features/            画面の部品（地図、クイズ、ケース、復習、進み具合）
  lib/content/         教材の読み込みと確かめ
  lib/progress/        学習の記録（ブラウザの中に保存）
  lib/review/          復習の日にちの計算
tests/                 教材の確かめ・記録・復習のテスト
```

教材の決まりは、テスト（`npm test`）で機械的に確かめる。たとえば次のようなことを見る。

- 横断ケースの財務3表の数字が合っているか（資産の増減と負債・純資産の増減、貸借対照表の現金の増減とキャッシュフローの合計、利益剰余金の増減と当期純利益）
- つながる先のテーマが実在するか
- クイズが5問あり、正解の位置が偏っていないか
- 法務・税務のテーマに出典と時点があるか

### 手元で動かす

```bash
npm install
npm run dev           # 開発用のサーバー（http://localhost:3210）
npm test              # テスト
npm run build:pages   # 公開用に書き出す（out/ にできる）
```

公開は、`npm run build:pages` でできた `out/` の中身を `gh-pages` ブランチに置き、GitHub Pages で配信している。

## Claude Code での開発

このアプリは、AI のコーディング支援ツール [Claude Code](https://www.anthropic.com/claude-code) と一緒に作った。私はプログラマーではない。何を学びたいかを決め、案を選び、読んで「難しい」「足りない」を伝える役を担った。コードと教材の文を書いたのは Claude Code である。

1. **要件を決める**：「経営者に必要な知識を学びたい」という相談から始めた。Claude Code が選択式で質問し（分野、使う端末、学び方、置き場所）、答えを仕様書にまとめた。分野をばらばらに教えず、財務3表をものさしにしてつなげる、という柱もこのとき決めた
2. **デザインを選ぶ**：雰囲気の違うラフ案を作ってもらい、「経営の地図」の案を軸に、「決算書ノート」の案を合わせる形を選んだ
3. **作る**：Claude Code が画面と、教材の決まりを確かめるテストを作った。教材は、分野ごとに書き手のサブエージェントに分けて書かせた
4. **確かめる**：書いた本人ではないサブエージェント（reviewer）に、数字の誤り、教材どうしの食い違い、法令の条文や制度の説明の誤りを探させ、見つかったものを直した。法務・税務は、法令と公的機関のページを出典にした
5. **直す**：使ってみて「日本語が難しすぎる」と伝えた。Claude Code は文の決まり（です・ます、短い文、用語には説明を付ける）を作り、教材と画面の文を全部書き直した。つながりの地図も、線が多すぎて読めなかったので、分野を1つ選んでつながりを見る形に作り直した
6. **足す**：「ポーターの競争戦略のような専門的な内容も入れたい」と伝えた。Claude Code が調査用のサブエージェント4つに、13分野の定番の理論・名著を並行して調べさせ、分野ごとに3つずつ候補を出した。そこから39テーマを足し、基礎のテーマと混ぜて、内容の近い順に並べた。原典で確かめられなかった事実は書かない、という決まりで書かせた

このアプリの開発では、Codex（OpenAI）は使っていない。

## 対応環境

- iPhone の Safari と、パソコンのブラウザ（Chrome・Safari など）
- 学習の記録はブラウザの中に保存するので、ブラウザのデータを消すと記録も消える。必要なら「記録の書き出し」で控えを取る

## 注意

- 教材は学習用で、経営・法務・税務の助言ではない
- 教材の会社・人物・数字はすべて架空
